# 🌟 Freya Quest — Playful Companion Work & Habit Tracker

> **Core Philosophy:** *Work → Complete tasks → Earn XP → Character reacts → Level up → Stay motivated.*
> **Base Strategy:** SWE first, AI as your superpower. One main resource → Learn → Practice → Build → Move on!

---

## ✨ Features

1. **Interactive Companion Mascot (Freya)**:
   - Features the high-resolution 3D companion character in overalls, yellow scrunchie, and freckles.
   - Dynamic emotional states:
     - **Happy 😊**: Active tasks completed today with golden halo.
     - **Excited 🤩**: Milestone / Level Up celebration with fanfare and confetti!
     - **Sleepy 😴**: Idle state waiting for your first daily win (never guilt-tripping!).
     - **Proud 👑**: Streak champion status.
     - **Encouraging 🌟**: Supportive guidance when starting.
   - **Interactive Poke & Speech Bubbles**: Tap Freya to hear cheerful synthesized voice chimes and supportive quotes!
   - **Dressing Room / Wardrobe**: Unlock accessories (AI Researcher Visor, LeetCode Ninja Band, Golden Sparkle Halo, IITM Scholar Mortarboard, Grandmaster AI Crown) as you level up.

2. **Preloaded with Your Complete AI Guide & Handwritten Daily Schedule**:
   - **Compulsory Habits (from handwritten note)**: Aarti/Darshan, Lemon Water 🍋, Pooja with Audio, Write Prapti, Ahnik & Vachbook, Clean Study Area, Daily Plan.
   - **First 7 Days Kickoff**:
     - Day 1: Create `ai-lab` repo & pick Kaggle tabular dataset
     - Day 2: Kaggle Pandas EDA notebook (shape, missing, 3 plots)
     - Day 3: Andrew Ng W1 + NumPy Linear Regression from scratch
     - Day 4: StatQuest Gradient Descent + 1 DSA problem
     - Day 5: Logistic Regression from scratch (NumPy vs scikit-learn)
     - Day 6: Train/val/test split + overfitting demo + BFS problem
     - Day 7: Mini-report notebook + README push + 2-min verbal explanation
   - **DSA & LeetCode Track**: Graphs (BFS/DFS), Dynamic Programming (1D foundations), Daily LeetCode problem.
   - **Flagship Project**: PatientTriage.ai v2 (Real ED triage dataset, hybrid XGBoost model, recall optimization, FastAPI safety overrides).
   - **After Studies Balance (from handwritten note)**: Flute 🪈, Harmonium 🎹, Gym 🏋️‍♀️, Crochet 🧶, Artwork 🎨, Driving 🚗, Mansi & Cheshta catchup, Book reading.
   - **College & IITM Work**: Degree coursework, practice quizzes, lab assignments.

3. **Part 7 Operating Mode Switcher**:
   - 🎒 **Busy College Day (20–45 min)**: Minimum day checklist (1 concept, 20m code, 1 DSA, 1 note) — *Never zero days!*
   - ☕ **Normal Day (1.5–2.5 hrs)**: Full study loop (Learn + Code + PatientTriage step + commit + explain aloud).
   - 🚀 **Free / Weekend Day (4–6 hrs)**: Deep build + project experiment + weekly review.

4. **"Only 20 minutes. Start?" Focus Timer**:
   - Dedicated 20m focus sprint widget with SVG progress ring.
   - Awards bonus **+35 XP** and level progress upon completion!

5. **Resource Verdicts & Roadmap Navigator**:
   - Part 2 Verdicts Table (Andrew Ng ✅ NOW, Kaggle ✅ NOW, StatQuest 🆘 STUCK, fast.ai ❌ SKIP, etc.).
   - Part 9 Real-World Problem of the Week interactive worksheet.
   - Original handwritten note photo viewer.

6. **Zero-Lag Game Audio**:
   - Built-in Web Audio API sound effects for clicks, task completions, level ups, and companion pokes (no external audio files needed).

## 🚀 Running the App

The dev server is running live at:
```bash
http://127.0.0.1:5173/
```

To start it anytime in terminal:
```powershell
cd C:\Users\Admin\.gemini\antigravity\scratch\companion-tracker
npm run dev
```

To build for production:
```powershell
npm run build
```
